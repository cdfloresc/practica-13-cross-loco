# 🌍 Cross-LOCO — Práctica 13

Evaluación de generalización transnacional Out-of-Distribution (OOD) mediante la estrategia Leave-One-Country-Out (LOCO) en 6 países.

## 🚀 Arquitectura
- **Backend**: FastAPI (Python) sirviendo evaluación LOCO transnacional.
- **Frontend**: React + Vite + Country Selector + Recharts Bar & Radar.

## 🐳 Ejecución con Docker
```bash
docker compose up --build
```
Accede a `http://localhost:5173` o `http://localhost`.
